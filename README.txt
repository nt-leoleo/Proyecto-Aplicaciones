# Proyecto Aplicaciones

Este proyecto es una página web que implementa varias aplicaciones interactivas, como:

1. **Calculadora**: Realiza operaciones matemáticas básicas.
2. **Sistema de gestión de compras de supermercado**: Permite gestionar una lista de compras.
3. **Analizador de palabras**: Analiza palabras y proporciona estadísticas como longitud, número de vocales, etc.

## Estructura del proyecto

- `index.html`: Página principal del proyecto.
- `assets/`: Contiene recursos como imágenes y fuentes.
  - `fonts/`: Fuentes utilizadas en el proyecto.
  - `images/`: Imágenes utilizadas en el proyecto.
- `css/`: Archivos de estilos CSS.
- `js/`: Archivos de scripts JavaScript.

## Cómo usar el proyecto

1. Abre el archivo `index.html` en tu navegador.
2. Explora las diferentes aplicaciones disponibles en la página.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
